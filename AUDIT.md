## Corrections applied before publication

**Schedule evaporation restated to 7.15%.** An earlier draft quoted "approximately 13%". That figure
is not produced anywhere by this pipeline. The committed code computes **7.15%** (3,635 booked
slots/week → 3,375 effective; 260 lost). The 13% figure most likely arose from confusing evaporation
with the **no-show base rate of 15.06%** — these are different quantities, because overbooking
recovers part of each no-show slot and most early cancellations get refilled. Both are now checked
separately in the table above. The earlier verification of this figure also used a tolerance that was
far too loose to be meaningful; it has been tightened to 0.5%.

## What this audit covers

**Covers:** that every number published about this project is reproduced by the committed pipeline,
within a stated tolerance.

**Does not cover:** whether the simulated environment resembles any particular real organisation.
It does not, and does not claim to. See the data disclosure at the top of the README.
